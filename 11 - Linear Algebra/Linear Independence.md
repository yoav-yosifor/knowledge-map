## Core Idea

A set of vectors is linearly dependent if some non-trivial linear combination of them gives the zero vector, and linearly independent otherwise.

## Key Equation

*$S=\{v_1,\dots,v_n\}$ is linearly dependent (ת"ל) if:*

$$
\exists\,(\alpha_1,\dots,\alpha_n)\neq 0:\qquad \alpha_1v_1+\alpha_2v_2+\cdots+\alpha_nv_n=0
$$

**Derived From:** definition, using a non-trivial [linear combination](../11%20-%20Linear%20Algebra/Linear%20Combinations.md) that equals zero. If no such combination exists, $S$ is linearly independent (בת"ל).

## Supporting Formulas

- Any set that contains the zero vector is linearly dependent.

## Derivation Outline

1. Form a linear combination of the vectors equal to $0$.
2. If a non-trivial choice of scalars works, the set is dependent.
3. If only the trivial choice works, the set is independent.
