## Core Idea

An initial value (Cauchy) problem is an ODE together with a known value of the function at a starting point, which fixes the integration constant and selects one particular solution.

## Key Equation

$$
y(x_0)=y_0
$$

**Derived From:** the source's usage — state the known initial condition (e.g. $y(0)=1$), then substitute it into the general solution to find the constant $c$. If other constants remain (e.g. a physical constant in the equation), another given data point is needed before $c$ and the rest can all be determined.

## Supporting Formulas

- Substituting the initial condition into the [general solution](../12%20-%20Ordinary%20Differential%20Equations/General%20and%20Particular%20Solutions.md) gives an equation for $c$.
- Each unknown constant needs its own piece of given data.

## Derivation Outline

1. Write the known initial condition as an equation $y(x_0)=y_0$.
2. Substitute it into the general solution to find $c$.
3. Substitute $c$ back to get the particular solution.
