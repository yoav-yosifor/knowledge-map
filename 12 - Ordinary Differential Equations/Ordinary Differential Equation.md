## Core Idea

An ordinary differential equation (ODE) is an equation in which the unknown is a function, given only through some relation between it and its derivatives.

## Key Equation

$$
y=f(x)\quad\text{such that the equation holds for all } x \text{ in the domain}
$$

**Derived From:** definition. In an ordinary equation the unknown is a variable; in an ODE the unknown is the function itself. We look for a function that satisfies the relation among its derivatives for every value of $x$ in the domain, and a solution is an explicit function $y=f(x)$.

## Supporting Formulas

- The ODE is classified by its [order and degree](../12%20-%20Ordinary%20Differential%20Equations/ODE%20Order%20and%20Degree.md).
- A solution can be a [general or a particular solution](../12%20-%20Ordinary%20Differential%20Equations/General%20and%20Particular%20Solutions.md).

## Derivation Outline

1. Identify the unknown function $y$.
2. Read the given relation between $y$ and its derivatives.
3. Find the explicit function $y=f(x)$ that satisfies it for all $x$ in the domain.
